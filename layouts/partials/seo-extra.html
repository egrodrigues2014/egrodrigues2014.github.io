{{/* Head additions the theme does not provide. Called from the local baseof override; see layouts/_default/baseof.html for why that override exists. 1. hreflang. Toha v4.16.0 emits none at all — verified, zero occurrences in all three languages — while getting right. For a trilingual site that is a real SEO gap: without it a search engine treats the three versions as unrelated pages, or as duplicates. Built from .AllTranslations, which lists only versions that actually exist and includes the current page, so the set is reciprocal as the spec requires. The value uses the same expression as in baseof (.Language.Locale falling back to .Language.Lang) so the two can never disagree: en, es-ES, pt-BR. Skipped entirely on pages with a single version — a blog post with no translation gets nothing, which is correct. 2. Pre-launch noindex. Paired with layouts/robots.txt and driven by the single switch params.prelaunch, so launching is a one-line change rather than a hunt for references.
